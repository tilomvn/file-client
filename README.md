# Environment Requirement
* Must have Java 8 or above.
# How to build and run
* Clone source, go to file-client directory, type command [mvnw verify] to build.
* Go to directory target, type command [java -jar file-client.jar] to run.
# Deployment
* This application working on client-server architecture, so we can run it in any enviroment.
* Ensure a server address which can be setted in application.properties file.
* Default server address is: http://localhost:4001/
